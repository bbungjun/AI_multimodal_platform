# Issue148 — existing-style Master console

## Problem and implementation

Audited administration and operational reads existed only as backend Interfaces.
G10D connects them to /master without changing the studio landing page, login or
provider behavior. Existing Session epoch isolation, request guard and QueryClient
replacement apply; normal Users cannot mount console queries even by direct URL.
One frontend slice reuses Panel/Button/Badge and responsive usage-table styling.

Overview separates real/synthetic account counts, current-Plan Credit flows,
meter units, daily charges, terminal success denominator and model/state p95.
Users and Audit use bounded keyset pages. Nullable samples and projected cycle
renewals are labelled rather than presented as measured or already written.
Runtime parsing consumes explicit fields; raw errors/objects/profiles are never
rendered. Decimal-string aggregate Credit is formatted with BigInt, including
values beyond JavaScript safe integer totals. No floating-point money parsing.

Commands require selected target, reason code and confirmation. A synchronous
in-flight guard prevents duplicate clicks; request UUID/payload are frozen before
send and retained for explicit retries. A received replay receipt is shown as
already processed, not another bonus. No automatic retry or browser promotion.
Unconfirmed submissions remain frozen; abandoning navigation warns to inspect
Audit. Session replacement drops the form and refuses delayed responses.
